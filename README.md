# Prüfgelände in Daten

Statische Seite (Datenblatt im Blaupausen-Look). Keine Build-Schritte nötig.

## Auf GitHub Pages veröffentlichen
1. Neues Repository anlegen (für Pages im kostenlosen Plan öffentlich).
2. `index.html`, `assets/`, `.nojekyll` und `README.md` direkt in die oberste Ebene hochladen.
3. Settings → Pages → Source „Deploy from a branch“ → Branch `main`, Ordner `/ (root)` → Save.

Die Seite lädt nur die Schriften von Google Fonts nach, sonst ist alles enthalten.
